1 · Basics

Goal: find your way around a worksheet, type data, use AutoFill, and label columns with units.

Start Excel for the web

  1. Go to microsoft365.com and sign in with your Campbell account.
  2. Choose Excel, then Blank workbook.
Screenshot to comeExcel for the web: a blank workbook, with the ribbon, Name Box, formula bar and grid labeled.

Words you need

  • Cell: one box, named by column letter + row number: C4.
  • Range: a block of cells, first and last joined by a colon: C4:C6 means C4, C5, C6.
  • Formula bar: shows what's really in the selected cell (the number you typed, or the formula behind a result).

Type data

  1. Click a cell and type. Press Enter to move down, Tab to move right.
  2. To fix a cell, click it and retype, or double-click it to edit inside it.
  3. Put a header in the top row of each column, with the unit in the header: Volume (mL).

AutoFill a series

  1. Type 1 in one cell and 2 in the cell below.
  2. Select both, then drag the fill handle (the small square at the bottom-right corner of the selection) down. Excel continues 3, 4, 5, ….
Screenshot to comeThe fill handle, and a series being dragged down.
Common mistake: units in the cells. If you type 24.15 mL, Excel stores text, not a number, and can't average it. Put units only in the header. Quick check: numbers line up on the right of a cell, text on the left.
Check yourself: in a blank workbook, type the headers Sample, Trial, Volume (mL) in A1:C1, then AutoFill Trial numbers 1, 2, 3 in B2:B4. Do the numbers sit on the right side of their cells?

2 · Bringing data in

Goal: get data into Excel without retyping it, and get your workbook back out as a file.

Paste from another page (fastest)

  1. Copy the data (on the Lab page, the Copy data button does this).
  2. In Excel, click the cell where the top-left value should go (for the Lab, A1).
  3. Paste: Ctrl+V (Windows) or ⌘+V (Mac). Each value lands in its own cell.

Open a file

  • .xlsx is an Excel workbook: data, formulas, formatting and charts.
  • .csv ("comma-separated values") is plain text: just the values, separated by commas. No formulas or formatting are saved in it.
  • To open either one in Excel for the web, upload it: on microsoft365.com choose Upload (or drag the file onto the page), then click it to open it in Excel.
  • Do your work in an .xlsx. If you start from a .csv, save your work as an .xlsx so your formulas and formats are kept.
Screenshot to comeUploading a file on microsoft365.com and opening it in Excel for the web.

Get your workbook out (for the checker)

  1. Excel for the web saves automatically to OneDrive.
  2. To get a file on your computer: File → Create a Copy → Download a Copy (some versions say File → Save As → Download a Copy).
  3. The file goes to your Downloads folder as an .xlsx.
Screenshot to comeFile menu → Download a Copy.
Common mistake: pasting in the wrong place. Everything shifts by a row or column, and the Lab's instructions (B1, B2, row 3) no longer match. Press Ctrl/⌘+Z to undo and paste again at A1.
Desktop Excel: File → Open opens .xlsx and .csv directly; Data → From Text/CSV imports a .csv into an existing workbook. Save with File → Save As and choose Excel Workbook (.xlsx).

3 · Sorting & filtering

Goal: put a table in order without scrambling it, and show only the rows you want.

Sort a whole table by two columns

  1. Click any one cell inside the table (don't select a single column).
  2. Data → Custom Sort (also under Home → Sort & Filter → Custom Sort).
  3. Make sure My data has headers is checked, so the header row stays on top.
  4. Sort by Sample, A to Z. Then Add Level: then by Trial, Smallest to Largest. Click OK.
Screenshot to comeThe Custom Sort dialog with two levels: Sample, then Trial.
Common mistake: sorting one column by itself. If only the Volume column is selected, Excel sorts just those numbers, and every volume ends up next to the wrong sample. The data are now wrong, and nothing looks broken. If Excel asks, choose Expand the selection. If it already happened, undo with Ctrl/⌘+Z.

Filter

  1. Click inside the table, then Data → Filter. Arrow buttons appear in the header row.
  2. Click the arrow on Sample, uncheck Select All, check B, click OK. Only Sample B's rows show.
  3. Filtering hides rows; it doesn't delete them. Clear it with the same arrow → Clear Filter, or turn Filter off.
Keep tables apart. Excel treats every block of touching cells as one table. In the Lab, column E stays empty so that sorting the data in A:D never pulls in the results table in F:I.
Check yourself: after sorting, pick any row. Is its volume the same one that was beside that sample and trial before you sorted?

4 · Formulas & references

Goal: let Excel do the arithmetic, and understand what happens to a formula when you copy it down.

Formulas

  • Every formula starts with =. Example: =C4/1000 changes mL in C4 to L.
  • Operators: + - * / and ^ for powers. Use parentheses to control the order.
  • The cell shows the result; the formula bar shows the formula. To see every formula at once: Formulas → Show Formulas.

Relative references move when you fill down

If D4 holds =C4/1000 and you drag the fill handle down, D5 gets =C5/1000, D6 gets =C6/1000, and so on. That's usually what you want: each row uses its own volume.

Fixed references ($) don't move

Moles of NaOH = volume (L) × concentration. The concentration is in one cell, B2, for every row. Write it as $B$2 so it stays put when you fill down: =C4/1000*$B$2.

  • $B$2 fixes both column and row. (B$2 fixes only the row, which also works when filling down.)
Common mistake: forgetting the $. The first row is right; every row below uses B3, B4, … (blank or wrong cells), so the answers are 0 or wrong.
Shortcut: while typing a reference, press F4 (Windows) or ⌘+T (Mac desktop) to add the dollar signs. Or just type them.

5 · Statistics

Goal: summarize replicate measurements with the mean, standard deviation and %CV.

The functions

FunctionWhat it gives
=AVERAGE(C4:C6)mean
=MEDIAN(C4:C6)middle value
=MIN(...), =MAX(...)smallest, largest
=COUNT(...)how many numbers
=STDEV.S(C4:C6)standard deviation of a sample (divides by n − 1)
=STDEV.P(C4:C6)standard deviation of a whole population (divides by n)

STDEV is the older name for STDEV.S; it gives the same answer.

STDEV.S or STDEV.P?

Your three trials are a small sample of all the titrations you could run, so use STDEV.S. STDEV.P is only for when you have every member of the group (rare in the lab). With 3 trials, STDEV.P comes out about 18% too small.

%CV: precision on one scale

%CV (coefficient of variation, or relative standard deviation) = SD ÷ mean × 100. If the mean is in G4 and the SD in H4: =100*H4/G4. A lower %CV means more precise replicates; it lets you compare samples with different means. %CV has no units, so it's the same whether you use volumes or moles.

Each sample is a block of 3 rows, so the ranges can't be filled down (G5 would become D5:D7). Type each sample's range, or type row 4 and edit the ranges in rows 5–8 (or use FILTER, below). The %CV formula can be filled down from I4 to I8.

Efficient way (optional): FILTER

One formula per column that can be filled down: =AVERAGE(FILTER($D$4:$D$18,$A$4:$A$18=F4)). Use the same pattern with STDEV.S, MEDIAN, MAX, MIN and COUNT.

  1. $A$4:$A$18=F4 compares every sample letter with the one in F4, giving a list of 15 TRUE/FALSE values (TRUE only on that sample's rows).
  2. FILTER($D$4:$D$18, …) keeps the moles on the TRUE rows: that sample's three values.
  3. AVERAGE (or STDEV.S, …) works on those three values, just as if you'd typed D4:D6.

The ranges are fixed with $; only F4 is relative, so filling down to row 5 makes it F5 = "B" and picks Sample B's rows. Typed alone in a cell, =FILTER($D$4:$D$18,$A$4:$A$18="B") "spills" its three results into the cells below, a good way to see what it returns. If no letter matches (a typo or a stray space), you get #CALC!. FILTER works in Excel for the web and Microsoft 365, not in Excel 2019 or older.

n should be 3 for every sample. COUNT counts only cells that hold numbers, so a 2 here means a trial is missing or was typed as text.

Common mistake: the wrong rows. =AVERAGE(D4:D18) averages all five samples together, and a range that's off by a few rows mixes two samples. Each sample needs its own three rows: A is D4:D6, B is D7:D9, … E is D16:D18 (after sorting). A %CV far bigger than the others is a hint that its SD range is wrong.
Check yourself: which sample in your lab data has the lowest %CV? Is that the same as the one with the smallest SD?

6 · Formatting ranges

Goal: show numbers to the right number of decimals, in scientific notation when they're very small, and make a table easy to read.

Decimal places

  1. Select the cells (drag across them).
  2. Home → Increase Decimal or Decrease Decimal (the .0 / .00 buttons) until you see the number of places you want.
  3. Or Home → Number Format dropdown → Number, then set the decimal places.
Screenshot to comeThe Number group on the Home tab: Number Format dropdown, Increase/Decrease Decimal.

Scientific notation

  1. Select the cells, then Home → Number Format → Scientific.
  2. Adjust the decimals with Increase/Decrease Decimal: 2.515E-03 has 3 decimals and means 2.515 × 10⁻³.

Make it readable

  • Bold the header row: select it, Home → Bold.
  • Borders: select the table, Home → Borders → All Borders.
  • Column too narrow? You'll see ####. Double-click the right edge of the column's letter to fit it.
Common mistake: typing rounded numbers. Formatting changes only what you see; Excel keeps the full value for later calculations. If you retype a rounded result, you lose that precision and the cell is no longer a formula.
Lab A formats: moles (D4:D18) and Mean, SD, Median, Max, Min (G4:H8 and J4:L8) in Scientific with 3 decimals; %CV (I4:I8) with 3 decimals; n (M4:M8) as a whole number. Center the results table: Home → Center.
Check yourself: click a result you formatted to 3 decimals. The cell shows 3 decimals; does the formula bar show the formula?

7 · Making a plot

Goal: make an XY (Scatter) chart of measured data, with the right column on each axis.

Scatter, not Line

For measured data, where x is a number you set or measured, always use Scatter (XY). A Line chart treats the x values as labels and spaces them evenly, whatever their values. With volumes 0.50, 0.75, 1.00, 1.25, 1.50, 2.00, 3.00, 4.00 L, the jump from 2 to 4 L takes the same width as 0.50 to 0.75 L, and the curve comes out the wrong shape:

Make the chart

  1. Put the x column on the left of the y column(s); Excel uses the leftmost selected column as x.
  2. Select the data with its header row (for Lab B: A3:C11). The headers become the series names.
  3. Insert → Scatter and pick Scatter (markers only, the first choice).
Screenshot to comeInsert tab → Scatter (X, Y) menu, with "Scatter" (markers only) highlighted.

Check and fix the series: Select Data

  • Right-click the chart → Select Data. Each series is one set of points with a name, X values and Y values.
  • Click a series → Edit to fix its ranges. Add makes a new series: set the name (click its header cell), X values and Y values.
  • Two y columns sharing one x column make two series on one chart, as in Lab B.
Common mistakes. A Line chart (the curve is distorted, and the x column may even be plotted as a series of its own). Selecting only the y columns: Excel then plots against 1, 2, 3, …. Selecting the header row as data: the y range should start in row 4, not row 3.
Desktop Excel: Insert → Insert Scatter (X, Y) or Bubble Chart → Scatter; Select Data is also on the Chart Design tab.

8 · Chart elements

Goal: label a chart so a reader understands it without asking you: title, axis titles with units, legend.

Add the elements

  1. Click the chart. Use the Chart tab (or the Format pane that opens beside the chart) to turn on Chart Title, Axis Titles and Legend.
  2. Click each placeholder ("Chart Title", "Axis Title") and type the real text. A placeholder left in place counts as missing.
Screenshot to comeExcel for the web: chart selected, Chart tab with Chart Title, Axis Titles and Legend.

What to write

  • Axis titles: quantity, then unit in parentheses: Volume (L), Pressure (atm), Concentration (M). Absorbance has no unit: Absorbance.
  • Chart title: what the graph shows, e.g. "Pressure vs. volume of a gas at two temperatures".
  • Legend: needed when there are two or more series, so readers can tell them apart. The entries come from the series names; if they say "Series1", fix the name in Select Data → Edit → Series name (click the header cell). With one series, turn the legend off; it adds nothing.
Common mistake: axis titles without units. "Pressure" alone leaves the reader guessing atm, kPa or mmHg.
Desktop Excel: the + (Chart Elements) button beside the chart turns each element on and off.

9 · Chart text & axes

Goal: make the chart readable: text big enough to read in a report, and axes that show the data well.

Font size

Excel starts the title at 14 pt, axis titles at 10 pt and the legend at 9 pt. In our labs, the title, axis titles and legend are all 12 pt.

  1. Click the chart title (it gets a box around it).
  2. Home → Font Size → 12.
  3. Repeat for each axis title and the legend.
Screenshot to comeChart title selected, Home → Font Size set to 12.

Axis range (minimum and maximum)

  • Double-click (or right-click) the axis numbers → Format Axis → Axis Options → Bounds, and set Minimum and Maximum.
  • Start an axis at 0 when zero is meaningful and you want to show proportions. Leave room above the highest point so it isn't on the edge.
  • In the same pane: Number sets the format of the axis numbers (e.g. 2 decimals), and gridlines can be turned on or off under Chart Elements.

Axis ranges are part of a good figure but aren't graded in the labs.

Common mistake: changing the whole chart's font. Selecting the chart frame and changing the size changes the axis numbers too. Select each element by itself.

11 · Capstone 1: Mass vs. Volume

Goal: a finished, report-ready plot of mass vs. volume, with every element the Key Assessment asks for.

The six elements

  1. A descriptive title: say what is plotted, e.g. "Mass vs. Volume of Ethanol".
  2. A subtitle with your name, in a smaller font than the title.
  3. An x-axis label with units: Volume (mL).
  4. A y-axis label with units: Mass (g).
  5. The data, as an XY (Scatter) plot: mass on y, volume on x.
  6. A regression line with its equation and R² value.

Plot the data

  1. Select both columns with their headers (A1:B9), then Insert → Scatter. Volume is the left column, so it goes on x (Module 7).

Title and a subtitle with your name

  1. Turn on the chart title (Module 8), click it and type the descriptive title.
  2. Click at the end of the title text and press Enter to start a second line. Type your name.
  3. Select just the name line, then Home → Font Size and pick a smaller size than the title (for example, title 14 pt, name 11 pt).
Screenshot to comeA chart title with a second, smaller line holding the student's name.

Excel has no separate "subtitle" box: the subtitle is the second line of the chart title. A separate text box isn't attached to the chart and can be lost when you copy it.

Axis labels with units

Add Axis Titles (Module 8) and type Volume (mL) for x and Mass (g) for y.

Regression line, equation and R²

  1. Click a data point → Chart → Trendline → Linear (Module 10).
  2. In Format Trendline, check Display Equation on chart and Display R-squared value on chart.
  3. Leave Set Intercept unchecked: the assessment uses standard linear regression (y = mx + b).
  4. Drag the equation box to a clear spot so it doesn't cover the points. The slope is the density in g/mL.

Make it report-ready

  • Show measured data as markers; a line joining the points isn't needed (the regression line is the model).
  • No 3-D, shadows or picture backgrounds; keep the text readable.

Into Word or a PDF

  1. Click the chart's border to select the whole chart, then copy (Ctrl/⌘+C).
  2. Paste into a Word document (Word for the web works too). To hand in a PDF instead, save the Word file as PDF: File → Save As → PDF (desktop) or File → Export → Download as PDF (Word for the web).
  3. Download your Excel workbook (File → Create a Copy → Download a Copy) and attach both files to the Blackboard assignment.
Common mistakes. A Line chart (its trendline uses 1, 2, 3, … for x, so the equation is wrong). Your name on the same line as the title, or the same size. "Chart Title" or "Axis Title" left in place. Axis labels without units.

10 · Trendlines

Goal: fit a straight line to calibration data, read the slope and intercept, and use them to find an unknown's concentration.

Add a linear trendline

  1. Click a data point (or the chart), then Chart → Trendline → Linear.
  2. In Format Trendline, check Display Equation on chart and Display R-squared value on chart.
  3. Leave Set Intercept unchecked: let the fit find its own intercept.
Screenshot to comeFormat Trendline pane: Linear, Display Equation, Display R-squared.

Reading it

For Beer's law, A = εb·c, so a plot of absorbance (y) against concentration (x) is a straight line. In y = 12345x + 0.0034, the slope 12345 M⁻¹ is εb, and the intercept should be close to 0. R² near 1 (e.g. 0.9990) means the points lie close to the line.

The same numbers in cells

HI
4Slope=SLOPE(B4:B9,A4:A9)
5Intercept=INTERCEPT(B4:B9,A4:A9)
6R²=RSQ(B4:B9,A4:A9)

Order matters: known y's (absorbance) first, then known x's (concentration). The chart's equation is rounded; these cells keep full precision, so calculate with them, not with numbers copied from the chart.

Finding an unknown

Solve A = m·c + b for c: c = (A − b) ÷ m. With the unknown's absorbance in E4: =(E4-$I$5)/$I$4, then fill down. The $ signs keep the slope and intercept fixed (Module 4).

Common mistakes. SLOPE with the ranges swapped (x's first). Plotting the unknowns with the standards. Forgetting the intercept: A ÷ m instead of (A − b) ÷ m. An unknown whose absorbance is outside the standards' range is an extrapolation: dilute it and measure again.

12 · Capstone 2: Ethanol–water solutions

Goal: find the density of five ethanol–water solutions from mass vs. volume data, tabulate the regressions, and plot density against composition.

Plot 1: all five solutions on one plot

  1. Select A1:F9: the volume column and all five mass columns, with headers.
  2. Insert → Scatter. Excel makes five series that share the volumes in column A as x; the headers become the series names (Module 7).
  3. Format it as in Capstone 1: a descriptive title, your name as a smaller second line of the title, and axis titles with units (Module 11).

Color by solution, with a legend

  • Excel gives each series its own color automatically. To choose your own: click one solution's points → Format Data Series → Marker → Fill (and Border). With five series, pick colors that are easy to tell apart (a light-to-dark sequence suits 0% → 100%).
  • Keep the legend on; if it says "Series1", fix the name in Select Data → Edit → Series name.
Screenshot to comeFive colored series with a legend and a regression line on each.

A regression line for each solution

Click one solution's points (only that series is selected) → Chart → Trendline → Linear. Repeat for each of the five. Leave Set Intercept unchecked. Equations on the chart are optional; your table holds the numbers.

Plot 2: density vs. % ethanol

  1. Select H1:I6 (% ethanol and slope = density, with headers), then Insert → Scatter. % ethanol is the left column, so it goes on x.
  2. Add a descriptive title, your name as a smaller second line, and axis titles with units: % Ethanol (by mass) and Density (g/mL).

What the plots tell you

Each slope in Plot 1 is a solution's density. In Plot 2 the points don't fall on a straight line between water (about 1.00 g/mL) and ethanol (about 0.79 g/mL): the mixtures are a little denser than that line predicts, because ethanol and water molecules pack together more closely than either liquid alone.

Into Word or a PDF

Copy both plots and the table (select H1:K6, copy) into a Word document, save as PDF if you like, and attach it with your Excel file in Blackboard (Module 11).

Common mistakes. Selecting only some mass columns. A trendline on only one solution. Two solutions in the same color. The table's SLOPE using the wrong mass column, or the ranges swapped. Typing "25%" in the table, or plotting textbook densities instead of your own slopes in Plot 2.
